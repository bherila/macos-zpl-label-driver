## Procedure

Commands/steps actually executed, not merely planned. Exclude secrets and private payloads.

## Expected and observed results

State the oracle, exact counts/sequences/errors and differences. A successful exit code alone may not validate the behavior. A printed label must be physically observed for H evidence.

## Artifacts

Sanitized logs, screenshot, bitmap digest, scanner pass counts, timing, relevant PR/workflow URL. Keep raw private material outside the repository and disclose any omitted evidence.

## Limitations / next action

List untested conditions, blocked gates, uncertainty or required maintainer work. Do not describe the configuration as qualified beyond the observed scope.
